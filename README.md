One Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a whole story in the few words a passer-by sees in a phone's network list.

## Entry

> **My WiFi Died For Your Sins** (26 characters)

The router gave its life so you could scroll in peace. A martyr with a blinking light.

## How it works

`main.ts` (Node 22, standard library only, no network, no wall clock) reads the entry from `entry.txt` and writes it to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`, defaulting to `output/` in the repo root).

```sh
node main.ts
```
